# easyjs-utils

> Libreria leggera di helper JavaScript per la manipolazione del DOM, gestione eventi e classi CSS — senza dipendenze.

---

## 🚀 Introduzione

**easyjs-utils** è una micro-libreria JavaScript (≈2KB minificata) che semplifica operazioni comuni sul DOM:
- Selezione rapida di elementi
- Gestione di eventi con funzioni shorthand (`onClick`, `onSubmit`, ecc.)
- Aggiunta/rimozione/toggle di classi CSS
- Manipolazione HTML e stili
- Helper per validazione form e lettura stili (`getStyle`, `cssWidthPx`, ecc.)

Perfetta per progetti in **Vanilla JS** o come **base utility** per piccoli script frontend.
